# تقرير مراجعة استجابة HR

الفرع: `hr-responsive-refactor`. لم يُنفذ Push أو Merge.

## نطاق المراجعة

تم تتبع Routes في `App.js` و`Dashboard.jsx`، ومصدر القائمة في `Sidebar.jsx`، والـimports المحلية. القائمة تُحمّل من `/api/sidebar-navigation/me`؛ لم تتوفر قائمة الحساب الفعلية للاختبار.

الصفحات المنفذة: الموظفون، الأقسام، المسميات، العقود، الحضور، الإجازات، أذونات الموظفين (وثلاثة مساراتها البديلة)، والصفحة الرئيسية للموظف. المكونات المتفرعة: مصمم الهيكل التنظيمي، نظرة الهيكل التنظيمي، وإدارة مسارات الأذونات. الحصر يشمل 42 Dialog و13 Table و4 Tabs containers. التفاصيل ومواقع الأنماط في `../hr-inventory.json`.

تقارير الموظف والعقود والحضور وإعدادات الورديات وBioTime وExcel والإجازات موجودة داخل هذه الصفحات. `DailyAttendanceReport` و`MonthlyAttendanceReport` يتعاملان مع حضور الطلاب؛ لم يُعدلا باعتبارهما خارج HR.

توجد في روابط الصفحة الرئيسية أسماء لوحدات أخرى مثل الرواتب والعهد والتدريب وتقارير HR؛ لا توجد Routes مقابلة منفذة لها في النسخة الحالية. لم تُنشأ وظائف أو مسارات جديدة. لم يتوفر عنصر مستقل باسم «أدوات الموظفين» في القائمة المحلية المحملة من الخادم، لذا تمت مراجعة أذونات الموظفين وأدوات الصفحة الرئيسية المتاحة.

## أسباب المشاكل

- `NavigationShell` يملك حجز مساحة القائمة بالفعل ويستخدم Desktop من 1200px. لم يكن من الصحيح إضافة تعويض آخر داخل HR؛ لم يُعدل.
- الحد الأدنى لأعمدة صف الحضور كان 1355px قبل الفجوات، وللعقود 1325px؛ أكبر من مساحة المحتوى المتاحة على اللابتوب.
- فلاتر الحضور والعقود كانت تجمع عروضًا ثابتة كبيرة، وبعضها يبدأ عند Tablet.
- جدول الأذونات كان يفرض 1350px، وعمود خطوات مسار الإجازة وحده يفرض 520px.
- بعض أنماط HR كانت تنتظر `xl` للاستفادة من عرض Desktop. لم توجد شروط إخفاء 1599/1600 في صفحات HR الحالية.
- قواعد typography العامة تتغلب على `sx` العادي، فتمنع أحجام عناوين HR من الظهور كما حددتها الصفحة.
- بعض شبكات النماذج بقيت بعمودين على الهاتف واختصرت أسماء الحقول.
- ملف `rtl-forms-fix.css` يحتوي قواعد عامة بـ`!important` ويُستورد في معظم أقسام التطبيق. بقي دون تعديل لتجنب تأثير يتجاوز نطاق المهمة.

## التحقق

- **بناء الإنتاج نجح مع تحذيرات** عبر `GENERATE_SOURCEMAP=false node node_modules/react-scripts/scripts/build.js`، بالنسخة النهائية بعد تعديل نماذج الهاتف (`../hr-build.log`). لم تُنشر المخرجات.
- اختبارات ملفات الموظفين وتنسيق الحقول والتنقل: **9/9 نجحت** (`../hr-tests.log`).
- مقارنة AST مع HEAD: ملفات الصفحات الـ11 تختلف فقط في خصائص العرض واستيراد أنماط HR؛ لا تغيير في handlers أو state أو API أو permissions (`logic-check.log`).
- اختبار العقد الموجود مسبقًا: **2 نجحا، 1 أخفق**. الإخفاق يكشف قواعد CSS العامة في الملف غير المعدل `rtl-forms-fix.css`؛ ليس إخفاقًا مخفيًا أو اختبارًا تم تجاوزه (`contract-test.log`).
- معاينة Chrome headless بملف شخصي مستقل وdeviceScaleFactor=1: 8 صفحات × 11 مقاسًا = **88 تحميلًا ناجحًا**. المقاسات: 1920×1080، 1600×900، 1536×864، 1440×900، 1366×768، 1280×720، 1200×800، 1024×768، 430×932، 390×844، 375×812. النتائج في `final-visual-results.json`.
- لم تُرصد زيادة في عرض document عن viewport في هذه العينات. التمرير الأفقي المرصود يخص تبويبات الموظف والإجازات في الجوال. تمت مراجعة صور من Desktop والجوال، وليس الاعتماد على قياس عرض document وحده.
- فُتحت 7 أنواع من الحوارات على 1366px و390px (14 حالة): إضافة وردية، إعداد الورديات، تنبيهات العقود، إضافة قسم، مسمى جديد، إذن جديد، وطلب إجازة. كلها فتحت وبقيت داخل عرض الشاشة. حوار الموظف اختُبر أيضًا ضمن جولة الصفحات.

## حدود التحقق

- المعاينة تستخدم بيانات تجريبية وقائمة Sidebar بديلة بنفس عقد العرض؛ لم تختبر القائمة المحملة لحساب حقيقي أو الصلاحيات الفعلية أو كثافة بيانات الإنتاج.
- لم تُجرّب عمليات حفظ/حذف/اعتماد أو مزامنة BioTime أو رفع Excel أو إرسال بيانات حقيقية. مقارنة الكود واختبارات الموظف تحمي من تغييرات المنطق لكنها ليست اختبار تكامل للخادم.
- مراجعة 42 حوارًا في المصدر لا تعني تجربة كل حالة وكل تبويب فيها ببيانات فعلية. العينات المرئية المذكورة أعلاه هي ما جُرّب بالفعل.
- لم تُرفق صور المقارنة المذكورة في نص الطلب؛ لذلك لا توجد مقارنة pixel-by-pixel مع لقطة Zoom 80–90%.
- لا يمكن اعتبار كل معايير قبول HR مُثبتة على بيئة الإنتاج، خصوصًا مع بقاء CSS العام القديم. يلزم قبول بصري على حساب وبيانات فعلية قبل اعتماد النتيجة كتحقق شامل.

## إعادة تشغيل المراجعة

من جذر المشروع:

```powershell
node ui-review/hr-audit.cjs
node ui-review/hr-verify-logic.cjs
node ui-review/hr/serve.cjs
# بعد تشغيل Chrome بملف شخصي معزول وremote-debugging-port=9224:
node ui-review/hr/visual.cjs
node ui-review/hr/dialogs.cjs
```

خادم المعاينة محلي على `127.0.0.1:3102`. يمنع fixture طلبات الكتابة ولا يستخدم بيانات اعتماد فعلية. لقطات الشاشة وملف المتصفح ومخرجات webpack مستثناة من Git.
